Aura - Multi-Tenant Virtual Try-On Commerce SaaS

Aura is a premium, multi-tenant Django platform built specifically for modern fashion brands, technology startups, and digital agencies. Designed from the ground up to offer Virtual Try-On (VTO) workflows alongside a complete digital storefront, Aura bridges the gap between traditional ecommerce and AI-driven fashion.

🌟 Why Choose Aura?

Unlike standard single-store ecommerce templates, Aura is built on a Role-Based Access Control (RBAC) SaaS architecture. It provides isolated dashboards for System Administrators, Brand Owners (Vendors), and Customers. With a security-first backend, robust multi-tenant object isolation, and a beautifully responsive Tailwind CSS frontend, Aura gives you the foundation to launch a powerful fashion marketplace.

The Ultimate Differentiator: The pre-built Virtual Try-On (VTO) architecture. Aura ships with the UI, queuing systems, and customer fit-profile database necessary to let customers visually try on apparel. (Note: You simply need to plug in your own Replicate API token or Stable Diffusion backend to activate the AI image generation).

🔥 Key Features

👨‍💻 System Administrator

  • Complete oversight via the powerful Django Superuser portal.
  • Manage global settings and platform-wide configurations.
  • Approve, suspend, or create Brand Owner tenants.
  • Manage user access and oversee all database entities.

Brand Owner (Vendor)

  • Tenant Isolation: A strictly isolated dashboard. Vendors can only access and mutate their own data.
  • Store Management: Configure brand logos, names, and storefront banners.
  • Advanced Catalog: Create rich products with complex variants, assigning specific colors, sizes, and stock.
  • Order Fulfillment: Track customer orders specifically tied to the brand's products.

Customer Experience

  • Modern Storefront: Browse products, filter by categories, and experience a fluid, Tailwind-powered UI.
  • Fit Profile: Customers can upload reference photos and save their sizing data.
  • Virtual Try-On (VTO): Select an apparel variant and request a visual try-on preview (Requires API config).
  • Commerce: Full shopping cart and checkout architecture ready for Stripe/Khalti webhook integration.

🛠️ Technology Stack

Built for production stability and developer extensibility:

  • Backend: Python 3.12, Django 5+
  • Frontend: HTML5, Tailwind CSS, minimal vanilla JS (Lightweight & Fast)
  • Database: PostgreSQL ready (SQLite for local dev)
  • Deployment: Fully Dockerized with Gunicorn and WhiteNoise for static asset serving.

⚙️ System Requirements

  • OS: Ubuntu/Debian Linux recommended for production.
  • RAM: 1GB Minimum / 2GB+ Recommended
  • Dependencies: Docker & Docker Compose
  • AI Hardware: Standard VPS if using the Replicate API integration. A dedicated GPU server is only required if you choose to self-host the Stable Diffusion weights.

📚 What's Included?

Warning: Important Notices

VTO AI Generation: Aura provides the complete software architecture, UI, and database models for Virtual Try-On. However, it does not include free external AI processing. You must configure your own REPLICATE_API_TOKEN to activate the AI generation feature.

Checkout: The checkout flow requires you to input your own Stripe or Khalti API keys.
