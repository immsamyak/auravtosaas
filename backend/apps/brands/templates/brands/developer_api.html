API Documentation

Use these endpoints to integrate Aura with your custom storefronts.

GET /api/v1/brand/products/
List all active products 
curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/v1/brand/products/" \
  -H "Authorization: Bearer YOUR_API_KEY"
POST /api/v1/brand/orders/
Create a new order 
curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/v1/brand/orders/" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_phone": "+1234567890",
    "items": [
      { "product_id": 1042, "quantity": 1 }
    ]
  }'
GET /api/v1/brand/products/{id}/
Get single product details 
curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/v1/brand/products/1/" \
  -H "Authorization: Bearer YOUR_API_KEY"
GET /api/v1/brand/collections/
List all active collections 
curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/v1/brand/collections/" \
  -H "Authorization: Bearer YOUR_API_KEY"
GET /api/v1/brand/orders/history/
View recent order history 
curl -X GET "{{ request.scheme }}://{{ request.get_host }}/api/v1/brand/orders/history/" \
  -H "Authorization: Bearer YOUR_API_KEY"
